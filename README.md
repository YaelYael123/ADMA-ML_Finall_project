<div align=justify> The project was done for two courses, advanced data mining and analysis (which has a separate repository) and machine learning, which I studied in the third year.
Advanced data mining and analysis is a course that includes technologies and methods which enable the collection and processing of huge amounts of data from a wide variety of sources - structured and unstructured, known as Big Data.</div> 
<div align=justify> Machine learning is a course where central methods for analyzing information in an automatic manner were taught. The methods are based on complex mathematical models. As part of the course, emphasis is placed on the intuition behind each of the methods studied.</div>
<br>
<div align=justify> In the project we've built an application for predicting requested prices for apartments. First, we used the knowledge we’ve learned in Cross Mining and advanced data analysis, then we wrote a crawler that collected data on apartments for sale and requested prices from the Madlan website using scraping, then we pre-processed the collected data.
After that we used information from a course to learn the preparation and built an elastic net prediction model of the property price, then we returned to information from an advanced data mining and analysis course and built a flask service and an html page that would allow entering the data relevant to the model and running the model, so that finally the predicted price would be printed on the page.</div>
<br>
<div align=justify> Since the project crossed two courses it was challenging but very instructive and made it possible to apply the material learned from both courses.</div>
